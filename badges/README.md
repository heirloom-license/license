# Badge usage

Show buyers the promise. Use the badge only on software released under an
**unmodified** Heirloom License.

## Markdown (README)

```markdown
[![License: Heirloom 1.0](https://heirloomlicense.org/badge.svg)](https://heirloomlicense.org)
```

## In-app "About" box

> **Protected by the Heirloom License.** If this app is ever abandoned, its
> full source code is released to the public under MPL-2.0 — automatically and
> permanently. Learn more: heirloomlicense.org

## Variant label

When you want to show the exact terms, append the identifier:

```
License: Heirloom 1.0 · HL-1.0-MPL2.0-12mo
```

`heirloom-badge.svg` in this folder is the canonical artwork. Don't recolor or
alter it — a consistent badge is what makes the promise recognizable.
